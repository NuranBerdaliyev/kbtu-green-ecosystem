## Backend

Приоритетные исправления:

1. Добавить создание первого `ADMIN` через dev-seed или переменные окружения.

2. Починить WebSocket:

    * разрешить handshake `/ws-green/**`;
    * проверять JWT при STOMP CONNECT;
    * закрыть `/topic/admin/alerts` только для ADMIN.

3. Исправить Carpool:

    * не начислять награду без пассажиров;
    * запретить join после времени отправления;
    * блокировать поездку при конкурентном занятии места;
    * добавить максимальное количество мест;
    * валидировать координаты;
    * определиться со статусами `PUBLISHED` и `IN_PROGRESS`.

4. Исправить EcoWaste:

    * не доверять вес и заполненность обычному пользователю;
    * сохранять вес, прирост заполненности и тип отхода в `WasteLog`;
    * запретить депозит в заполненный контейнер;
    * добавить ограничения частоты/веса;
    * отправлять alert только при переходе через 90%;
    * добавить операцию очистки контейнера после вывоза.

5. Доделать административный backend:

    * настройки начислений;
    * корректное управление вакансиями и компаниями;
    * пагинация WasteLog;
    * при необходимости отдельные endpoints для очистки контейнеров.

6. Исправить Auth/Profile:

    * создавать `Profile` при регистрации либо возвращать пустой профиль вместо 404;
    * добавить backend logout с отзывом refresh-токена;
    * унифицировать ответы 401/403;
    * добавить актуальный `/auth/me`, чтобы frontend не хранил устаревшую роль.

## Frontend

1. Включить `requiresAuth` guard в router.

2. Сделать HR-раздел:

    * мои компании;
    * создание/редактирование компании;
    * мои вакансии;
    * создание/редактирование/удаление вакансий.

3. Доделать Admin Dashboard:

    * пользователи и назначение ролей;
    * подтверждение партнёрства компаний;
    * CRUD контейнеров;
    * очистка заполненности;
    * WasteLog;
    * настройки начислений.

4. Исправить Career UI:

    * форму отклика показывать только `STUDENT`;
    * кандидатов — только владельцу вакансии;
    * кнопки статусов показывать согласно текущему статусу;
    * выводить ошибки изменения статуса;
    * скрывать форму, если студент уже откликнулся.

5. Починить WebSocket:

    * заменить `/ws` на `/ws-green`;
    * передавать JWT в STOMP CONNECT;
    * корректно показывать состояние переподключения.

6. Исправить Carpool UI:

    * согласовать название `ACTIVE`;
    * обновлять EcoCoins после завершения;
    * исправить loading/error для вкладок «Мои» и «Я присоединился»;
    * добавить редактирование и удаление созданной поездки.

7. Исправить Profile:

    * загружать отклики только для студента;
    * нормально обрабатывать отсутствие профиля;
    * обновлять роль после её изменения администратором.

8. Доделать навигацию:

    * Companies;
    * Achievements;
    * HR-раздел;
    * административные подразделы.

9. Исправить EcoWaste UI:

    * показывать минимум 1 EcoCoin при весе до 100 г либо синхронизировать формулу;
    * блокировать заполненные контейнеры;
    * заменить фальшивое «сканирование» выбранной моделью подтверждения.

## Совместно решить

Два решения должны сначала принять оба backend-разработчика и фронтендер:

* что означает `ACTIVE`: опубликована поездка или уже началась;
* кто подтверждает вес отходов: контейнер, сотрудник или демонстрационный симулятор.

Без этих решений фронтенд и backend снова реализуют разную бизнес-логику.
