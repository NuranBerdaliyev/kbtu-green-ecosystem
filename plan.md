# План разработки KBTU Green Ecosystem

> Данный документ описывает полный цикл разработки проекта: от создания репозитория до финального деплоя. План построен таким образом, чтобы три участника команды могли работать параллельно, не блокируя друг друга.

---

# Состав команды

| Участник | Роль | Основная ответственность |
|----------|------|--------------------------|
| Backend Developer №1 | Backend / Core | Архитектура проекта, авторизация, пользователи, система геймификации |
| Backend Developer №2 | Backend / Modules | Бизнес-модули (Carpool, EcoWaste, Career) |
| Frontend Developer | Vue | Интерфейс, интеграция с Backend, пользовательский опыт |

---

# Общий процесс разработки

Разработка разбивается на несколько этапов.

Каждый следующий этап начинается только после завершения предыдущего.

```
Подготовка проекта

↓

Проектирование

↓

Backend Foundation

↓

Frontend Foundation

↓

Разработка модулей

↓

Интеграция

↓

Тестирование

↓

Документация

↓

Deploy
```

---

# ЭТАП 7. Gamification

Это центральная часть проекта.

Ее нельзя писать раньше.

К этому моменту уже должны существовать все модули.

---

## Backend Developer №1

Создает сервис:

```
GamificationService
```

Он отвечает за:

- EcoCoins
- ESG Rating
- достижения
- историю действий
- лидерборд

Никакой другой модуль не изменяет рейтинг напрямую.

Все изменения проходят только через этот сервис.

---

Подключает EcoWaste.

Все модули начинают использовать GamificationService.

- Railway
- Render
- VPS
- Docker

---

## Database

Развернуть PostgreSQL с PostGIS.

---

## Frontend

Собрать production-версию Vue.

- Vercel;
- Netlify;
- Nginx (при VPS).

---

## Домен и HTTPS

Настроить:

- доменное имя (при наличии);
- SSL-сертификат;
- переменные окружения.

# Финальная проверка

Перед сдачей проекта необходимо убедиться, что:

- регистрация работает;
- авторизация работает;
- роли работают корректно;
- создание поездок работает;
- присоединение к поездкам работает;
- начисление EcoCoins выполняется автоматически;
- контейнеры отображаются и обновляются;
- WebSocket передает изменения без перезагрузки страницы;
- вакансии отображаются;
- отклик на вакансии работает;
- лидерборд обновляется автоматически;
- профиль пользователя показывает актуальные EcoCoins, ESG-рейтинг и историю активности;
- Swagger содержит документацию по всем API;
- проект запускается локально через Docker без ручной настройки;
- production-версия доступна по публичному адресу.
